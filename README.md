# UNA ADORACIÓN — sitio web

Landing de una página en HTML, CSS y JS puro (sin build). Abre `index.html` o sirve la carpeta con cualquier servidor estático:

```bash
python -m http.server 5500
```

## Contenido por completar
- `audio/en-el-rio.mp3` — audio del reproductor del hero y del carrusel.
- `js/carousel.js` — canciones, portadas y rutas de audio del carrusel.
- `js/main.js` — `WHATSAPP_NUMBER` para el formulario de contacto.
- `index.html` — fechas de eventos, enlaces de plataformas, correo y fotos de la galería.
